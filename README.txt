ARTMARKETY — FIRST WEBSITE SKELETON

Upload index.html, style.css and script.js to the ROOT of a public GitHub repository named artmarkety.
Then go to Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
Site URL should become https://YOUR-USERNAME.github.io/artmarkety/ once published.

This is a PROTOTYPE. The logo and raspberry hero are CSS placeholders, not final approved artwork.
The text is draft; the service detail pages are placeholders. Contact form copies the request; it does NOT send emails.
No old site or domain is modified.
